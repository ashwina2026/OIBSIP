# Weather Application 🌦️

## Project Description

The Weather Application is a beginner-level Python project that allows users to check the current weather of any city using a simple graphical user interface.

It uses the Open-Meteo API to retrieve real-time weather information.

## Features

- Search weather by city name.
- Display current temperature in Celsius.
- Show current weather conditions.
- Display weather icons.
- Show humidity percentage.
- Display wind speed in km/h.
- Handle invalid city names.
- Display error messages for internet or API connection problems.

## Technologies Used

- Python 3
- Tkinter
- Requests Library
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## Installation

1. Install Python 3 on your computer.
2. Open Terminal.
3. Navigate to the OIBSIP project folder.
4. Activate the virtual environment:

```bash
source .venv/bin/activate
```

5. Install the required library:

```bash
python -m pip install requests
```

No API key or paid subscription is required.

## How to Run

Run the following command from the main OIBSIP folder:

```bash
python Task2-WeatherApp/main.py
```

## API Used

**Open-Meteo API**

- Weather API: https://open-meteo.com/en/docs
- Geocoding API: https://open-meteo.com/en/docs/geocoding-api
