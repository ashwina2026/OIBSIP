# Random Password Generator

## Project Description
A beginner-level Python application that generates random passwords using a simple and user-friendly graphical interface.

## Features
- Generate random passwords.
- Select password length between 4 and 64 characters.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Display generated passwords.
- Copy passwords to the clipboard.
- Basic input validation.

## Technologies Used
- Python 3
- Tkinter
- Random module
- String module

## Installation

1. Install Python 3.
2. Open Terminal.
3. Navigate to the main OIBSIP folder.
4. Activate the virtual environment:

```bash
source .venv/bin/activate
```

No additional third-party packages are required for this project.

## How to Run

Run the following command from the OIBSIP folder:

```bash
python Task1-RandomPasswordGenerator/main.py
```
